# 內頁版型比較

使用者要求先發布目前版本，再比較網站內頁設計。正式閱讀頁維持原樣；提案以既有「處置與流程」文章生成，不維護三份醫學內容副本。

- A 學術閱讀：三欄結構、連續段落、頁內目錄。
- B 章節卡片：以章節分卡、編號與留白，偏分段複習。
- C 臨床筆記：深色主題導覽與白色筆記區，標題邊線與重點標示。

設定位於 `config/layout-previews.yml`，source_id 必須是已公開的頁面 id。生成程式 `scripts/build_previews.py` 使用與正式版相同的已渲染正文和引用；只調整相對連結以對應提案網址。

輸出至 `03_outputs/web/layout-previews/`，經相同白名單建置與連結檢查。首頁自動收錄比較入口和各提案。公開搜尋仍只索引正式文章，避免相同內容重複佔據搜尋結果。

使用者選定版型後再決定是否套用全站。設定 enabled 為 false 並重建可移除本工具產生的提案頁；不刪手動檔案。
