# 臨床流程圖製作規範提案

日期：2026-11-15。本文保存前輪研究提案與當時查核範圍。使用者後續要求依此重畫並形成實作規範；現行規則見 AGENTS.md 與 [製圖手冊](clinical-diagram-playbook.md)，本輪完成程度見 [重製驗收](clinical-flow-redesign-audit.md)。以下「尚未實作／待確認」描述的是提案階段，不代表後續狀態。

本次目的：讓讀者能帶著一個學習情境，知道還需要哪些資料、何種條件改變下一步、可採取哪些具體行動，以及何時重新評估。不是只把主題摘要排列成節點，也不把指南中保留彈性的選項改成自動處方。

## 1. 查到的做法與採用範圍

沒有查到能將某一繪圖引擎稱為醫學流程圖「全球最佳」的依據。較有用的比較是：流程是否可判讀、行動是否具體、來源邏輯是否保真，以及案例能否走完。以下是具代表性的現行官方規格、實際指引原圖與奠基方法，不是工具排名或完整系統性回顧。

| 參考 | 實際查核範圍 | 對本專案的啟示 |
| --- | --- | --- |

WHO、HL7 的規格適用於更大的數位健康系統；本站只借用內容轉譯與核對方式，這輪不建立 FHIR／CQL 平台、病人資料庫或診療計算器。GLIA 與 BRIDGE-Wiz 是較早的奠基工作，沒有把舊軟體包裝成新工具。

以下 SOP 與驗收表是依本專案需求提出的規則，不是上述機構逐字發布的標準。

## 2. 現有 SJS 圖的問題與改寫方向

已另由來源閱讀 agent 實際核對 Watanabe Table 3：PDF9／e96、PDF10／e97，並回查 CQ16：PDF11／e98。來源見 [Watanabe 紀錄](../02_sources/records/watanabe-2026.md)。這是來源核對，不是人工醫學審閱。

### 應保留的規則

本圖使用日本 2025 準則，不能改稱全球通用 SJS/TEN 標準。五項主準則為：

1. 黏膜皮膚交界處廣泛、嚴重的黏膜病灶；眼、口、生殖器是列舉，並非三處必須全有。
2. 廣泛紅斑與表皮壞死所致的糜爛／水疱等表現；受影響面積 `<10% BSA`，保留易剝離區與病程的註記。
3. 發燒；來源表格未指定數字體溫門檻。
4. 病理的表皮壞死變化；原文對充分發展病灶與細胞數的補充，不全部升格為硬門檻。
5. 排除 EMM 與細胞毒性抗癌藥藥理作用造成、非遲發型過敏的皮膚傷害；有抗癌藥暴露本身不等於此排除條件成立。

原文要求五項全部符合，並參照次要準則與完整病程。排除 EMM 的綜合判讀會用到嚴重度、治療反應與病理等資訊，這些資訊應在判讀主準則時可取得。

### 現圖缺失

- 把五項串成五個無條件步驟，容易暗示來源沒有規定的作業順序。
- 把次要準則及完整病程放在五項符合後面，呈現成事後附件，但其中資訊會參與第五項的判讀。
- 「已知有不符合」與「尚有未知」可能同時出現，現有出口未把優先次序與保留資訊說清楚。
- 出口沒有充分指出是哪一項未確認、缺什麼資料，以及如何回查。

### 建議結構

版本與適用範圍 → **一張五項主準則檢核卡**，每項保留「符合／不符合／未確認」及依據；旁接次要資訊、完整病程、病理及 EMM 的鑑別說明 → 一個整合判斷。

| 資訊狀態 | 可表達的結果 | 後續資訊與限制 |
| --- | --- | --- |
| 五項全部已確認符合 | 滿足本版所列主準則要求，仍結合完整病程判讀 | 保留版本、次要資訊與相關診斷／處置頁；不由網站自動確認個案診斷 |
| 至少一項確認不符合，不論是否另有未知 | 未滿足本版全部主準則，列出不符合項 | 同時保留未知項，不直接輸出「排除 SJS」 |
| 沒有已知不符合，但至少一項未確認 | 尚無法確認是否滿足全部主準則 | 列出缺少的病史、皮膚／黏膜範圍、病理或鑑別資料，回到相應核對步驟 |

這三態是本站整理資訊狀態的方式，不是原指引另訂的診斷分流。「符合4／未確認1」可以顯示進度，但**不可命名為「4/5 疑似 SJS」或賦予機率**。次要準則不能用來湊足主準則。

若需要具體切片位置、時機或其他檢查操作，須另有來源；不能由「病理未確認」自行補出程序。面積超過 SJS 門檻時可連到 TEN／國際分型比較，但不能只憑面積就自動判 TEN；恰為 10% 時也不能擅改不等號。

## 3. 憂鬱症反應不足：哪些資訊原本就能寫進圖

本 PDF 沒有統一的依從性百分比門檻、充分療程週數或「部分反應＝20–49%」定義。不能因為流程需要菱形，就自行新增這些切點。MDD adjunctive 的劑量也不能直接移用成躁期用藥。

### 轉躁必須成為明確的評估出口

「注意轉躁」至少要呈現需詢問的線索。NIMH 2025 症狀表可提供睡眠需求降低、活動增加、思緒奔逸、語速加快及異常誇大等例子；這是辨認線索，不是完整專業診斷準則。[NIMH 症狀與診斷段](https://www.nimh.nih.gov/health/publications/bipolar-disorder)。

依 NICE CG185 的選讀範圍，疑似躁症或有危險時要轉入緊急專業評估；已出現躁／輕躁且使用抗憂鬱劑單方時，另有考量停用抗憂鬱劑及抗精神病藥的建議。其1.5.3對尚未使用抗精神病藥或情緒穩定劑者列 haloperidol、olanzapine、quetiapine 或 risperidone，選擇仍保留共病、過往反應、副作用與偏好。不能把「有一項警訊」直接連到給藥，也不能繼續套一般 MDD 增量路徑。[CG185 1.2.2、1.5.2–1.5.3](https://www.nice.org.uk/guidance/cg185/chapter/recommendations)。

完整症狀組合、持續時間、排除條件、躁期劑量與監測仍需專門來源。NIMH 教育資料不能補成完整診斷演算法，NICE 的篩查轉介條件也不能改稱躁症診斷門檻。

### 腎肝功能應是逐藥的安全條件

已實際核對原廠 CYMBALTA 美國標示（修訂08/2023）PDF4 §2.7：GFR `<30 mL/minute` 時避免使用；慢性肝病／肝硬化另列避免使用。這可作為藥物候選條件，不是對整類抗憂鬱劑的一律規則。[原廠標示](https://pi.lilly.com/us/cymbalta-pi.pdf)。

因此製作時須保存來源使用的 GFR／eGFR／CrCl、單位、評估時間與適用情境；不能默默互換，也不能改成自訂 ALT 切點。GFR 達30以上只表示未觸發這一項門檻，不能推得此藥對該人安全或最適合。

本次也記錄到待審閱的適用範圍差異：CANMAT Q7.d 的一般 serotonergic 換至 MAOI 表述為至少2週，fluoxetine至少5週；該 duloxetine 標示 §2.9 對 duloxetine→MAOI 列至少5天，反方向則至少14天。不得自動合成單一換藥規則，須保存方向、藥對、版本及來源，另行確認處理方式。這輪未改寫既有換藥正文。

本次英國指引及美國標示是方法研究範例；未查臺灣全部核准標示、給付或可取得性，不稱在地處方流程已完成。

## 4. 建議採用的製作作業流程

### 步驟一：先寫用途與範圍

寫明要回答的臨床問題、族群、照護場域、起點、終點與版本；區分概念示意圖、正式準則核對圖、鑑別路徑及處置路徑。只做概覽時標為概覽，不能宣稱能帶著個案完成選藥或診斷。

### 步驟二：閱讀原始決策材料

先讀既有來源的原圖、表、相鄰正文、註腳與例外，逐條定位。將來源明述、本站整理與尚未給定的資訊分開。補充劑量、共病或臟器限制需要新增來源時，依第9節取得授權並先登錄；本次已獲查證授權，不代表未來每張圖均可自行外搜。

### 步驟三：先完成臨床決策表

未完成下表前，不開始選配色或自動排版。這是製作紀錄，不是讓讀者填寫的病人資料表，也不保存病例或學習進度。

| 必要欄位 | 寫入內容 |
| --- | --- |
| 節點／規則識別 | 穩定 id、用途與相關章節 |
| 進入情境 | 何人、何時、在哪種照護情境進入 |
| 所需資料 | 具名病史、藥物、檢查或量測；日期、基準、單位與取得方法 |
| 判斷條件 | AND／OR、全部／至少幾項、區間與邊界；只使用來源支持的規則 |
| 條件性質 | 必要條件、安全限制、診斷線索、選項偏向、患者偏好或編輯資訊狀態 |
| 下一步行動 | 檢查、核對、處理、轉介、具名選項及其必要條件，避免單寫「進一步評估」 |
| 限制與未知 | 哪些資訊缺少、如何回查；哪些結論不能推出；急迫情境是否另行優先處理 |
| 重評與去向 | 何時、用什麼指標重評；改善、惡化或無效分別回哪一段；未提供時明列缺口 |
| 依據 | source-id、版本、頁／推薦編號、表圖、原文推薦強度與例外 |

### 步驟四：依臨床語意決定節點與箭頭

- 可一起收集、沒有先後依賴的條件，合成一張有小項目的檢核／評估卡。
- 只有答案會改變下一步時，才畫判斷節點；箭頭標出具體條件，不用模糊的「需要／不需要」。
- 不把無條件知識條目排列成流程，也不把時間流程當成診斷積分。
- 多條件可同時成立時，明示並行處理或來源支持的優先次序，不強迫成互斥選項。
- 未知與已確認陰性分開。未知出口說明還缺什麼及如何取得，不只畫「資料不足」的死端。
- 硬條件、可考量選項與偏好使用不同文字／視覺標示；不能把 consider 升格為必做，也不能把來源明確要求弱化成任意選項。

### 步驟五：用藥先做候選條件與操作表

每個有臨床用途的給藥節點，至少要讓讀者能找到具名選項、選用依據、安全限制及監測，並區分起始量、目標量、上限、途徑、頻率、遞增與停換藥。缺少其中必要資訊時，不宣稱完成處方級流程。

共病、腎肝、QTc、代謝負擔、交互作用、先前反應及偏好常同時影響選擇，適合先用逐藥決策表篩選／比較，再連到行動；不能任意畫「某症狀→唯一藥物」或「腎功能達標→自動安全」。具體指標與數字逐藥引用，沒有數字時不補數字。

### 步驟六：寫出可走完的文字路徑

在繪圖前，以教學案例逐步回答：我現在知道什麼、還要問／查什麼、這個結果為何改變下一步、可採取什麼、何時回來檢查。若只得到「考量最佳化」「再評估」，必須回決策表補清楚；來源真的不足時明列缺口，不用空泛節點偽裝完整。

### 步驟七：分層排版，保留主圖資訊

主圖呈現可讀的臨床骨幹與關鍵條件；複雜的藥物安全、換藥、躁期或其他處置另做有內容的子流程／表格，仍連到同一疾病主題。重要門檻、急迫出口及主要動作直接可見，不能全部藏進滑鼠懸停或另一頁。細節與出處可展開，停用 JS 仍可讀。

檢核卡、判斷、處置卡、旁註及子流程入口分清。用連線表達邏輯或時間依賴，不以顏色或形狀單獨承擔醫學意義。避免交叉線、長句縮字與巨型單圖；重要準則清單不為了塞版而拆成假步驟。

繪圖引擎只負責呈現。可先以現有 Pele／SVG 驗證複合檢核卡與長中文；若它不能清楚表達所需內容，再比較其他可編輯 SVG／HTML 呈現。這不是立即更換工具或建置新平台的承諾。

### 步驟八：做臨床案例走查與邊界驗收

由來源與預期行動建立案例，不能從目前畫出的箭頭反推答案。教學案例明標為虛構測試，不當作已提供的病例。檢查包含正常路徑、缺資料、多條件並存、數值邊界、時間不足、藥物方向、例外與回饋迴圈；適用時核對單位、量表範圍及改善百分比的基準。

若尚未實作病人計算，案例可以在文字／決策表上走查；不能把「未做互動計算」等同「不需要檢查臨床邏輯」。圖形、文字版與正文應在同一案例下保持一致。

### 步驟九：獨立核對後再交付

至少分別做來源／醫學邏輯核對、案例可操作性核對及圖形閱讀核對。Agent 審查不升級為人工 reviewed。建置工具另查結構、引用、雜湊、可達性與資源；它不能證明臨床條件完整或行動適當。

版本、引用、圖像使用條件與目前適用範圍保留。正文、流程、操作表或藥品來源有實質修改時，回查受影響的條件與案例，更新衍生圖文、index／log 及已指定網站；失敗時不發布新的無效成品。

## 5. 兩個主題的最低驗收案例

以下為製作時的教學測試規格，未實作成病人資料輸入或自動診斷工具。

| 主題／情境 | 必須檢查的結果 |
| --- | --- |
| SJS：五項全部確認 | 不只顯示五格通過，還保留準則版本、病程及整合判讀 |
| SJS：四項符合、病理未知 | 未確認主④，不能輸出4/5疑似或確診 |
| SJS：一項不符且另一項未知 | 出口不互相矛盾；不符與未知項都保留，不宣稱排除疾病 |
| SJS：只有局部照片、發燒未記載 | 不能把全身面積或發燒推定為已知 |
| SJS：9.9%、10%、10.1%，或病程中面積變動 | 不等號及版本不被改寫，不只靠面積自動判 TEN |
| SJS：次要線索很多、主準則不齊 | 不以次要項補足主準則；病理 desirable 註記不升格硬條件 |
| MDD：虛構測試，基準PHQ-9 20，第4週18 | 算術改善10%；可觸發調整考量，但先保留暴露、耐受與診斷條件，不自動宣告TRD |
| MDD：劑量／時間或實際服用不清 | 不能算足量足時失敗，不虛構依從性百分比門檻 |
| MDD：部分改善且耐受佳／副作用明顯 | 呈現不同策略偏向，不把換藥與加藥畫成所有人必經的固定順序 |
| MDD：睡眠需求降低且活動、語速改變 | 明確核對其他資料並轉入合適評估，不憑警訊單項確診或繼續一般MDD增量 |
| 逐藥：該美國duloxetine標示，GFR29／30／未知 | 依原標示邊界篩選；30不等於全面安全；未知有核對出口 |
| 換藥：duloxetine↔MAOI及fluoxetine→MAOI | 方向、藥對、來源與時間窗分開；不同來源說法不被默默合併 |
| 任何路徑：安全風險與資料不足並存 | 資料尚缺不能延後應優先處理的安全評估；不自訂沒有來源的小時數 |
