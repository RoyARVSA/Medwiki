使用者已確認 AGENTS.md 的整體流程及本版網頁設計，授權本機建立與展示，GitHub 推送/部署後續處理。

- 學術知識入口＋文件閱讀頁；海軍藍、藍灰、白底，繁中正文，英文檔名。
- 電腦三欄，平板可收合，手機閱讀優先與左上返回。
- 動態 A：短暫淡入、章節定位、reduced-motion。

- 不加「依哪些來源整理」的介紹；保留段落引用、文獻清單、原始版本與未審閱/衝突。
- 使用現有 Python Markdown/YAML/Jinja 工具產生靜態網站，避免引入並非必要的 framework 目錄；靜態多頁與搜尋、篩選、引用面板、圖表、手機閱讀及輕量動畫可滿足已確認需求。Astro 為先前可選建議，非本版必要條件。

- 使用 config 與共同 templates，索引/網站輸出可重建，白名單發布不帶 raw/private。

驗收：全文整理與精確頁面引用；未解衝突並列；桌機/平板/手機可讀；搜尋與引用可操作；手動成果可收錄且去重；發布成品不含原始 PDF/私密資料；可本機預覽。
