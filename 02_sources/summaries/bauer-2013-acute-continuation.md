## 先抓住三個問題

- **目標是緩解與功能恢復，不能只看症狀下降一半。** 急性期追求 remission；延續期穩定緩解、防止同一病程復燃；維持期預防新一波發作，主要另由 Part 2 處理。[@F:2,8-9]
- **兩週的變化能提供訊息，但不是「兩週沒好就一定換藥」。** 本文支持早期量測，同時明說早期換藥仍缺充分前瞻性試驗，不宜過早或頻繁判定藥物無效。[@F:17-18]
- **延續期從緩解後起算。** 本文建議至少六個月；既往發作久、仍有殘餘症狀或精神病性特徵時，需要更長療程與追蹤。[@F:31-32]

## 文件範圍與證據怎麼讀

這是 **2013 年 Part 1** 的成人單極性憂鬱症指引，著重藥物、ECT、光照及其他生物治療。以更新的 MEDLINE 搜尋、其他指引與研究綜整及專家判斷形成建議；心理治療篇幅較短，雙極性憂鬱不在主要範圍。歷史文獻中「目前」或「新藥」的時間點是 2013 年，不能當成本網站已查核的最新狀態。[@F:1-4,39]

| 本文分級 | 要保留的意義 |
| --- | --- |
| CE A | 控制研究的充分療效證據；須考慮陽性與陰性試驗及比較條件 |
| CE B | 控制研究的有限陽性證據 |
| CE C1／C2／C3 | 分別來自未控制研究、病例報告、專家意見／經驗 |
| CE D／E／F | 分別是結果不一致、陰性證據、缺乏足夠證據；三者不能混成「沒效」 |
| RG 1／2 | 同為 CE A，但風險效益比不同 |
| RG 3／4／5 | 分別對應 CE B／C／D |
| Clinical consensus | 缺乏可回答該臨床問題的外部證據時之共識 |

**CE 是療效證據類別，RG 還納入安全、耐受與交互作用；兩者都不是本站人工審閱狀態，也不能直接換成 GRADE 或 CANMAT 的分級。** 表內分級定義與上述區別見 Table I。[@F:4-5]

## 定義、病程與評估

### 診斷採哪個版本

Table II 摘列 **DSM-IV 與 ICD-10**，不是完整診斷手冊。DSM-IV 摘要以過去兩週九類症狀中至少五項、包含低落或失去興趣至少一項，並有顯著痛苦／功能損害及相關排除條件；九類涵蓋心情、興趣、體重／食慾、睡眠、精神動作、精力、無價值／罪惡感、認知及死亡／自殺想法。該歷史表另列 bereavement 的處理。ICD-10 則依三項典型症狀及其他症狀組合分輕、中、重度，不能與 DSM 的項數混用。[@F:3,6]

**先確認是否有躁期、輕躁期或混合發作病史。** 診斷與治療計畫還要檢視焦慮、物質使用、精神病性表現、其他精神疾病、一般身體疾病、非精神科藥物及持續壓力；單靠量表或症狀表不能完成這些鑑別。[@F:2-3,7,9-10]

### 病程數字的限制

本文彙述的歷史流行病學資料包含終生盛行率中位數 16.1%（所引研究範圍 4.4–18%）、一年約 5–10%，女性約為男性兩倍；不同族群與量測不可互換。文章亦列反覆發作與殘餘症狀常見，不能把一次改善等同終生治癒。這些是本文當時的文獻綜述，未由本站另查目前地區盛行率。[@F:5-7]

### 追蹤症狀與功能

可用 HRSD／HAMD、MADRS 等他評量表，加上 BDI、PHQ-9、MDI 等自評。本文的反應分界為：[@F:17]

| 分類 | WFSBP 2013 的界線 |
| --- | --- |
| Non-response | 相對基線症狀嚴重度下降 **≤25%** |
| Partial response | 下降 **26–49%** |
| Response | 下降 **≥50%** |
| Remission | 無症狀或僅少數輕微症狀，例如 HRSD **≤7**，並考慮心理社會與職業功能改善 |

上述是本文的量測用語，不能擅自補成連續百分比下未明寫的分類規則，也不等同個案已完成臨床診斷。[@F:17]

急性期可行時建議至少每週接觸一次；延續期頻率因狀況調整，文中建議每一至兩個月一次。自殺風險、耐受性、身體狀況與治療關係要持續重評，不只記量表分數。[@F:10]

## 初始治療：嚴重度、偏好與安全一起考量

### 2013 年依嚴重度的建議

| 情境 | 本文的處理方向 |
| --- | --- |
| 輕度發作 | 心理教育、具療效證據的心理治療或適當支持；部分可支持性觀察約兩週。偏好藥物、既往藥物有效／曾有中重度發作，或非藥物嘗試未效時，再考量藥物 |
| 中度發作 | SSRI 及其他較新抗憂鬱藥是第一選擇，但本文排除 reboxetine；可合併心理治療 |
| 重度發作 | TCA、SSRI、SNRI 可使用；特定情境再考量 ECT 或 MAOI |

這組嚴重度建議原文標為 **CE A／RG 1**，仍須保留個別條件。藥物選擇還取決於既往反應、副作用、身體共病、其他用藥、過量毒性、可近性及患者偏好。不能將表格改讀為人人依序換同一種藥。[@F:2-3,10,13-14]

### 特徵與風險會改變處理

- **精神病性憂鬱**：初始治療建議抗憂鬱藥加抗精神病藥，CE B／RG 3；同時考慮後者的代謝及其他不良反應。[@F:15]
- Melancholic features 與住院、重症常重疊，但彼此不是同義詞；比較療效的統計差異不必然代表足夠的個人臨床差異。[@F:14-15]
- Atypical features 之 MAOI 證據來自特定歷史研究，與較新藥的直接比較不足；不可因「非典型」就跳過安全與交互作用評估。[@F:15]
- 自殺風險需首診及其後反覆評估；高度急迫風險須專科與密集照護，必要時住院。過量毒性較高的藥物應限制可取得的供應量。文中對未滿 25 歲或有自殺風險者，提到起藥後一週檢視及更密集追蹤。這些不是可單獨預測風險的打分規則。[@F:15-16]

## 藥物劑量、耐受與交互作用

### 劑量表怎麼使用

Table III 分開列起始劑量、標準劑量及部分藥物的血中濃度；高齡、心血管等共病者可能需較低起始量，地域可用藥與劑量也可能不同。**這是 2013 年來源表，不是現行核准劑量或個案處方表。** 例如 escitalopram 表列起始 10 mg/day、標準 10–20；mirtazapine 起始 15、標準 15–45；venlafaxine 起始 37.5–75、標準 75–375；這些數字均需與該藥風險及實際情境一起閱讀。[@F:8,13]

**citalopram 表內有「20–40 (60)」的歷史列法，而正文另警告高劑量 citalopram／escitalopram 的 QTc 延長；不能把括號 60 mg/day 擷取為目前可直接採用的上限。** 本次未另查各地現行仿單。[@F:8,13]

### 副作用的比較重點

Table IV 只做粗略比較，符號或空白不應當成個人的精確發生率。TCA 的抗膽鹼、姿勢性低血壓、傳導／心血管與過量毒性是重要取捨；SSRI 常見腸胃、活化／睡眠及性功能影響，並須注意出血、低鈉／SIADH 與部分高劑量 QTc 風險。Mirtazapine 較突出鎮靜與體重增加；SNRI 需留意血壓；agomelatine 的肝損傷及肝酵素監測另有警示。[@F:12-13]

不可將整類藥物簡化成「較新所以完全安全」。本文討論 SSRI 與 MAOI 或其他 serotonergic 藥物併用的 serotonin syndrome、不可逆 MAOI 與 tyramine／sympathomimetics 的高血壓危象，以及 CYP 抑制／誘導使併用藥濃度改變的風險。Table VI 是歷史交互作用清單，不能取代逐項用藥核對。[@F:11,13,19-22,37]

### TDM 與藥物基因學

TDM 對部分 TCA 的已建立濃度範圍、疑似未服藥、常規劑量卻毒性或無效、交互作用等情境較有幫助；不能假設所有 SSRI 都有同等明確的療效濃度目標。CYP 基因差異可能解釋部分濃度異常，但選藥用的許多候選基因／生物標記仍缺乏可直接常規應用的證據。**族群平均代謝差異不等於每位個人的代謝結果。**[@F:19-20,38-39]

## 早期評估與反應不足

### 第兩週知道什麼，又不知道什麼

早期改善常以約兩週內量表下降 20% 研究，與後續反應／緩解相關。但研究追蹤長短、受試者嚴重度及設計會改變預測效能；文章明說仍需更好的前瞻性試驗，才足以把早期無改善轉成明確的換藥規則。**兩週評估、兩至四週調整選項與八至十週可能達最大症狀下降，是不同層次的敘述。**[@F:2,17-18,25]

### 改策略前的檢查

先重評診斷、服藥遵從性、足夠劑量／療程、吸收／代謝、身體疾病與疼痛、其他用藥／物質使用及持續壓力。本文把確認 adherence 列為 Clinical consensus。增加劑量的支持在 TCA 與 venlafaxine 較清楚，不能把同樣策略無條件套到 SSRI。[@F:18-21]

### 換藥、合併與增強要分開

| 選項 | 2013 年支持及限制 |
| --- | --- |
| 換到不同類別 | SSRI 換 venlafaxine 或 tranylcypromine 被列為可考量，CE C／RG 4；須衡量部分效果流失與等待新藥起效 |
| 同類內換藥 | 有開放研究支持，但缺少妥善控制，不能把所報反應率當作確定成功率 |
| 兩種抗憂鬱藥合併 | SSRI 加 mirtazapine 等 presynaptic autoreceptor inhibitor，單藥未效時列 CE A／RG 2；venlafaxine 加 mirtazapine 可能增加不良反應 |
| 增強治療 | 加入非抗憂鬱藥，保留原藥部分效果；lithium、quetiapine 或 aripiprazole 是本文較有支持的選項 |

各策略不是固定必經順序，也不能用不同研究間的反應率直接排名。**不可逆 MAOI 不可與 SSRI 等 serotonergic 藥物任意重疊。** 本文換入／換出不可逆 MAOI 建議洗除期兩週，由 fluoxetine 換至不可逆 MAOI 時五週；一般藥物減量一至四週是本文的歷史共識，不能泛化為所有人的停藥速度。[@F:20-24]

### 增強治療的來源數字

| 選項 | 本文的量、評估與限制 |
| --- | --- |
| Lithium | 單藥未效時 CE A／RG 2；以 **2–4 週**評估，血清目標 **0.6–0.8 mmol/L**；反應者持續**至少 12 個月** |
| T3／T4 | 單藥未效時可考量，CE B／RG 3，需留意不良反應。多數早期 T3 試驗用 25–37.5 µg/day 增強 TCA；不能把它當所有情境的固定現行劑量 |
| Aripiprazole | 本文引仿單：起始 2–5 mg/day，每次調整最多增加 5 mg、間隔至少一週，最大 15 mg/day；注意 akathisia 等 |
| Quetiapine XR | 本文引仿單：晚上 50 mg 起始，第 3 天可至 150 mg，再視反應考量 300 mg/day；此適應情境未研究超過 300 mg/day；注意鎮靜、體重等 |

Aripiprazole／quetiapine 作為 lithium 增強的替代選項列 **CE A／RG 2**。這是**增強用途與該年代的來源數字**，不是精神病性憂鬱、精神分裂症或其他族群可以直接共用的劑量。Pindolol／buspirone 的增強證據較不一致，不能把加速早期反應等同確保最終效果。[@F:23-24]

### TRD 不只是「吃了兩種藥」

本文引監管用語是至少兩種不同抗憂鬱藥，**劑量、療程及遵從性均充分**後仍無具臨床意義的改善；亦討論多種 resistance staging 模型。未服足量、療程不足、未辨識雙極性及診斷／共病問題可能造成表面抗藥性。[@F:30-31]

MSM（Table V）包含期間、嚴重度、失敗療程、增強及 ECT，總分 3–15；本文給 mild 3–6、moderate 7–10、severe 11–15。其藥物試驗計入條件為足夠劑量至少六週。**但原表 Chronic 卻列「<24 months」，與前兩段重疊，故此處保留來源問題，不推定修正或製作計分工具。** 模型表現來自所引研究，不能當作對任意個案的已驗證預測。[@F:30-31]

## ECT、心理治療與其他選項

### ECT 的角色與後續

本文對需快速緩解的特定情境，例如重度精神病性或明顯精神動作遲滯、難治、拒食、急迫自殺風險、藥物不適用、既往有效或偏好 ECT，列為可首選的情境（**CE C／RG 4**）。這項分級是該建議框的情境建議，不宜當成對所有 ECT 療效研究的統一分級。[@F:3,25]

文中彙述 ECT remission 約 60–80%、最大反應常於二至四週，療程通常六至十二次；實際安排、側別與能量影響療效／認知取捨，需專科及麻醉評估。心血管、腦壓及其他風險應個別檢查。**急性 ECT 有效之後仍要規劃延續治療，不能把急性效果當作持久保護。** 未延續治療的歷史 relapse 估計範圍很寬，不能作為所有病人的單一風險數字。[@F:25-26,32]

### 心理治療、光照與輔助方式

| 方法 | 本文定位 |
| --- | --- |
| 心理治療 | 輕度可作初始選項；中重度、藥物部分反應或 adherence 問題可合併，CE B／RG 3。列 CBT、行為治療、IPT、CBASP，並提醒盲化及試驗方法限制 |
| 光照 | SAD 可考量，CE B／RG 3。文中方案包括早上 10,000 lux、每日 30–40 分鐘、2–4 週；有眼部風險者先眼科評估，亦注意光敏感及躁化等風險 |
| Benzodiazepines | 可短期協助焦慮／睡眠；需權衡鎮靜、認知／動作影響、依賴及物質使用史，通常限制約 **4–6 週**，不是長期抗憂鬱核心治療 |
| Wake therapy | 可作短期生物治療輔助，CE C1／RG 4，但恢復一晚睡眠後常 relapse，持續策略的證據與可行性另需考量 |
| 運動 | 輕至中度時可作藥物輔助，CE B／RG 3；試驗品質及效果量限制保留，不補造本文未規定的固定運動處方 |
| St. John's wort | 輕度且偏好替代療法者可考量，CE B／RG 3；製劑不一、交互作用及較長期資料不足，不能因草本就當作無風險 |

以上為原文相應情境，不可把不同方式的數字拆離族群或治療目的。[@F:24,26-29]

### 神經刺激與新興治療的年代差異

2013 年本文對 **rTMS** 的框列建議是：當時證據不足以推薦常規臨床使用，CE D／RG 5；對 **VNS** 則列藥物試驗反應不足者可能的選項，同為 CE D／RG 5，並保留對照試驗與開放長期資料的限制。這些是待與較後版本並列的歷史位置，不能直接當作今天的共同結論。Ketamine 與 multimodal serotonergic agents 在本文主要是新興方向，未形成可直接照用的完整療程規則。[@F:29-30,38-39]

## 延續期與停藥

**同一個使急性期達反應／緩解的抗憂鬱藥，以同一有效劑量延續**（CE B／RG 3）。延續期至少從急性症狀緩解後六個月起算；長既往發作可至九個月，殘餘症狀及精神病性憂鬱需更久。若藥物未消除殘餘症狀，可考量加心理治療。[@F:31-32]

第一波發作、延續期無 relapse 者可考慮逐步停藥，期間及剛停後密切監測；若減量時症狀回來，本文建議恢復原劑量至少另六個月後再嘗試。這是 2013 年的來源建議，不能跳過症狀原因的重評，也不等同所有長期／反覆病程均應此時停藥。Lithium augmentation 或 ECT 有效後的延續策略另有相關資料，維持期主要見 Part 2。[@F:21,23,31-32]

## 特殊情境：保留適用範圍

- **焦慮共病**：可選對兩種問題有證據的治療，藥物低量起始、慢增量以減少早期焦慮惡化（CE C1／RG 4）；CBT／IPT 也有支持。Benzodiazepines 僅作初期權衡，長期使用受到明確勸阻。[@F:32]
- **OCD 共病**：本文建議 clomipramine／SSRI（CE A／RG 2），並提到 OCD 用量可能較高；這不是可跳過劑量上限、安全或地域仿單核對的倍增指令。[@F:33]
- **物質使用**：先分清原發性憂鬱與物質誘發心情障礙。已確立兩者共病時需同時處理；活躍物質使用可能造成症狀時，先治療物質問題再重評亦有其情境。不能把文中兩種情境合成「一律先等戒除」或「一律只開抗憂鬱藥」。[@F:33]
- **高齡**：部分急性期證據不足，不能因此只按年齡排除治療；更重視姿勢性低血壓、抗膽鹼、心血管、腎肝功能與多重用藥。低量開始仍須依有效性適當調整；延續治療有預防 relapse 的證據。觀察研究的藥物危害關聯不能當隨機比較的因果結果。[@F:34-35]
- **一般身體疾病**：鑑別內分泌、神經、代謝、感染、免疫或其他病因與用藥效應；處理原疾病與憂鬱的優先順序取決於嚴重度及因果情境。文中分別談中風、失智、Parkinson's disease 等，不能據個別小型試驗排出所有共病患者的統一首選藥。[@F:35-37]
- **孕哺期**：本文依當時資料權衡胎兒／新生兒暴露與母體 relapse，並討論藥物、心理治療及 ECT；其中個別藥物與產後時窗屬歷史建議，不宣稱已核對目前周產期指引。哺乳時須觀察嬰兒睡眠、進食及行為變化；不從本頁推出個別孕婦或嬰兒用藥判斷。[@F:36,38]

## 回想與核對

<details class="recall-question"><summary>症狀下降 50% 就等於緩解嗎？</summary><p>不一定。本文把 ≥50% 下降稱 response；remission 仍須無症狀或僅少數輕微症狀，例如 HRSD ≤7，並檢視功能恢復。[@F:17]</p></details>

<details class="recall-question"><summary>第兩週沒有改善，是否可以直接判定一定要換藥？</summary><p>不能。早期改善具有預測價值，但本文對早期換藥的前瞻性證據仍保留限制；先重評診斷、adherence、劑量、療程與其他干擾，再共同選擇調整策略。[@F:17-21]</p></details>

<details class="recall-question"><summary>延續期的「六個月」從哪裡起算？</summary><p>從急性症狀達緩解之後起算。長既往發作、殘餘症狀及精神病性憂鬱可能需要更久，不是起藥六個月就自動停藥。[@F:31-32]</p></details>

<details class="recall-question"><summary>CE A／RG 2 是矛盾的分級嗎？</summary><p>不是。CE A 表示療效證據類別；RG 2 仍是 CE A，但風險效益比被評為中等。它也不等於 GRADE 等級或本站已人工審閱。[@F:4-5]</p></details>

<details class="recall-question"><summary>為什麼不能直接用 Table V 做 MSM 計分器？</summary><p>所提供表格的 Chronic 期間印為 &lt;24 months，與其他分段重疊，來源界線尚未釐清。另需保留充分試驗、期間、嚴重度等完整模型條件，不能由本站自訂修正。[@F:30]</p></details>
