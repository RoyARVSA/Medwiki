## 先掌握本篇的問題

## 2015 版本、範圍與證據框架

這份 Part 2 著重**單極性重鬱症的維持／預防性生物治療**，急性與延續治療另由 Part 1 討論。主要對象是成人，兒童青少年與高齡者只在小節補述；雙極性憂鬱症不在本篇治療範圍。心理治療僅簡要回顧，不能把「未在此分級」讀成沒有療效證據。[@M:1,3-4,13-14]

方法包括更新 MEDLINE 搜尋、既有指引與回顧／統合分析，以及 WFSBP 工作小組共識；無法取得共識時由主席／共同主席裁定。文件記載準備工作未接受商業組織財務支持，同時揭露部分作者的研究、顧問及演講利益關係。這些是**2015 年文件的方法與揭露**，不是對現今證據完整性的保證。[@M:3-4,14]

| 原分級 | 本篇含義與閱讀限制 |
| --- | --- |
| CE A | 足夠、符合方法標準的對照試驗支持；Table I 還規定陽性／陰性試驗、比較治療與非劣性等條件，不能僅用「有兩個 RCT」概括。 |
| CE B | 有限的陽性對照研究支持。 |
| CE C1／C2／C3 | 分別是非對照研究、病例報告、專家意見／臨床經驗。 |
| CE D／E／F | 分別是結果不一致、負向證據、缺乏足夠證據；**缺乏證據不等於證實無效**。 |
| RG 1／2 | 都來自 CE A，另依風險效益比為良好／中等而分級。 |
| RG 3／4／5 | 分別對應 CE B／C／D。 |

以上依 Table I 與正文整理，**不換算成 GRADE 或其他指引的治療線別**。摘要把 CE A–F 稱為五級，但正文與表格是六類；此用字差異保留。[@M:1,4-5]

## 病程：延續、維持與再發

本篇建議急性發作緩解後，先延續成功治療 **6–9 個月**；文內將維持治療的範圍界定為持續緩解後 6–9 個月起的長期治療。不要把這個階段界線直接當作所有研究一致採用的 recovery 定義。[@M:2,5]

**原文問題：**PDF 5／期刊 80 的 recovery 說明仍有「XYZ days/weeks」占位文字。本站不填入一個自訂天數；引用 relapse／recurrence 結果時保留研究／文件的命名與情境。[@M:5]

導論引用舊的追蹤研究，描述 MDD 經常反覆與留下殘餘症狀：曾有一次發作的患者，文中所引另一發作比例為 50–85%；三次發作後再發機會引用約 90%。這些跨研究、跨追蹤條件的數字是本篇回顧背景，**不能當作個人未來風險計算器**。嚴重或住院患者的殘餘功能／症狀負擔與慢性化情境，也不能直接外推到所有門診患者。[@M:3]

## 誰比較需要長期維持？

本篇明確舉出**至少三次重鬱發作，或先前再發頻率高（例如五年內兩次）**支持較長維持治療。啟動時間與長度仍需結合完整病程、先前反應、患者偏好、功能損害與副作用，而不是只用一個次數門檻。[@M:2,5]

Table II 的風險線索包括：[@M:6]

- 多次或近期發作：至少三次、五年內兩次、過去一年曾發作。
- 延續期或緩解時仍有殘餘／次臨床症狀、合併 dysthymic disorder。
- 過去發作較長或較嚴重，包括自殺相關表現、精神病性特徵。
- 停藥後曾復發；合併物質濫用或焦慮疾患。
- 一等親 MDD 家族史、30 歲以前發病。

**殘餘症狀、先前復發模式與後果同樣重要。**這是風險因子清單，並非每項有固定權重的量表，本文也沒有提供可加總的分數。[@M:2,5-6]

## 維持治療的基本工作

核心工作是心理教育、藥物治療、依從性監測與改善；可按個別需要加入 CBT 及生活型態策略。教育包括典型病程、藥物作用與副作用、早期警訊、治療預期與停藥規畫，也應知道患者同時使用的其他藥物。[@M:2,5-6]

穩定患者的就診頻率，原文範例從每月到每 3–6 個月；不穩定者需要更密集追蹤。新增身體疾病或改動處方時需重新考慮交互作用、血中濃度及副作用。這是原文的監測範圍，不能把較疏的頻率直接套到每位患者。[@M:6]

### 短暫波動與突破性發作

輕微、短暫的症狀波動（blips）可能自行緩解，但事前未必能確定哪一種會進展。原文允許在症狀不嚴重時短期觀察（例如至兩週），**但若個人過往模式顯示輕症總會接著惡化，就不能機械式等待**。監測早期警訊與依從性持續進行。[@M:6,10]

治療中出現新發作時，先回查未辨識的物質使用、身體疾病（如甲狀腺功能問題）及未規則服藥。原文的最佳化範例包括將 lithium 濃度調至 **≥0.6 mmol/L**、處理甲狀腺功能偏低及增加心理／追蹤介入；未改善時再走足量急性與延續治療，之後重新設計維持策略。這不是單一濃度就能解決所有治療失敗的演算法。[@M:11]

## 抗憂鬱藥：維持原來成功的治療

**急性與延續期有效的抗憂鬱藥，維持期原則上使用相同劑量**，原文列 CE A／RG 1。維持研究多是先篩選急性有效且能耐受者，再進行一至兩年的研究；這種富集設計限制了向全體患者外推。[@M:6]

| 原文列出的維持證據 | 藥物／情境 |
| --- | --- |
| CE A／RG 1 | citalopram、escitalopram、paroxetine、sertraline。 |
| CE A／RG 2 | amitriptyline、imipramine、nortriptyline、maprotiline；phenelzine、tranylcypromine；fluoxetine、fluvoxamine；venlafaxine、duloxetine。 |
| CE B／RG 3 | vortioxetine 的研究，以及 mirtazapine 與 amitriptyline 的長期比較研究等。 |

分級依本篇的藥物與研究敘述保留；不能把整個 SSRI／SNRI 類別一律改寫為 RG 1，也不以本篇分級宣稱目前所有藥物的排序。[@M:6-7,9]

### PREVENT 研究應怎麼讀？

文內整理的 PREVENT 先有 10 週急性期，再有六個月延續期；venlafaxine ER 在維持期重新隨機分派至繼續用藥或 placebo，fluoxetine 組則繼續原藥以維持盲性。維持第一／第二年的再發比例，原文分別報 venlafaxine 23%／8%、placebo 42%／45%。**不能把未重新隨機的 fluoxetine 組視為相同設計的直接對照。**[@M:7]

另段比較 venlafaxine 與 fluoxetine 的 24 個月無再發估計值為 71.9% 與 55.8%，整體優越性未達顯著，但有 treatment-by-time interaction。這些終點與分母／分析情境不同，不能只挑一組數字宣稱某藥確定較好。[@M:9]

## Lithium：證據、濃度與監測分開看

Lithium 維持預防單極性憂鬱再發，原文列 **CE A／RG 2**；若急性期用 lithium augmentation 達緩解，也可延續該策略。執行摘要對任一單藥無法維持穩定者，提出抗憂鬱藥加 lithium 的選項；但兩者的相對療效、以及合併是否一定更好，直接比較研究結果並不一致。**未顯示優越性，也不自動等於等效。**[@M:2,7-9]

| 濃度／監測問題 | 本篇記載 |
| --- | --- |
| 通常建議的維持濃度 | 0.6–0.8 mmol/L（mEq/L），末次服藥後 12 小時採血。 |
| 個別差異 | 原文容許約 0.4–1.0 mmol/L 的個別有效／耐受範圍，並非所有患者都應朝同一數值調整。 |
| 啟動或調量後何時測？ | 不早於 5–7 天，以反映穩定狀態；不能拿剛調量後的數值直接代替穩態評估。 |
| 長期監測 | 血中濃度每年 1–4 次；初期、高齡者或臨床狀況改變時更頻繁。甲狀腺、腎臟、甲狀旁腺／鈣等功能，原文舉每年 1–2 次及按臨床需要檢查。 |

濃度與採血條件見 PDF 7；監測與風險見 PDF 10。本篇同時列不同年齡、地區人群與製劑的每日劑量範例，不能用固定毫克數取代個別濃度／耐受調整。[@M:7,10]

重要風險包括腎絲球過濾與尿液濃縮功能下降、甲狀腺功能低下、甲狀旁腺功能亢進、體重增加、手抖與腸胃不適。原文強調中毒警訊、避免脫水及適當監測；腎功能、TSH、血鈣升高時的 PTH 等各有不同檢查目的。嚴重多尿的藥物處置只在原文特定情境討論，不能由此直接產生個人處方。[@M:10]

### 自殺相關證據不能和再發終點混用

原文對 lithium 的自殺相關效果列 CE B／RG 3，引用觀察研究、回顧及少數試驗。文內轉述單極性憂鬱統合分析的自殺／企圖年事件率為用 lithium 0.17%、未用 1.48%，相對低 88.5%；另一項「完成自殺」結果是不同終點。這些是**本指引轉述的研究結果**，原始研究未由本站逐篇重讀，不能寫成個人風險下降的保證。[@M:7]

## 其他藥物與長期副作用

| 介入 | 2015 年文件的證據與限制 |
| --- | --- |
| Quetiapine XR | 一項先開放治療／穩定、再隨機至持續 quetiapine 或 placebo 的維持單藥研究，CE B／RG 3；開放期劑量 50–300 mg/day、隨機期最長 52 週。原文報再發風險相對低 66%，但不可外推成未經篩選患者的普遍效果。 |
| Carbamazepine | PDF 8 列 CE C1／RG 4，僅有限小型研究；血中 4–12 μg/mL（17–50 μmol/L）的範圍更多源自抗癲癇作用，不能視為已驗證的單極性維持療效目標。 |
| 其他 mood stabilizers | 本版指出 valproate、oxcarbazepine、lamotrigine、gabapentin 缺少單極性維持的 placebo／雙盲比較試驗；這是當時研究範圍的陳述。 |
| Hypericum WS 5570 | 指定萃取物的研究，CE B／RG 3；不能把產品專屬證據改寫為所有 St John’s wort 製品都等效。 |
| 超生理劑量 levothyroxine 等增強策略 | 難治／預防失敗情境的有限證據，CE C／RG 4，原文要求密切注意潛在不良反應。 |

Quetiapine 與 carbamazepine／其他穩定劑／WS 5570 見 PDF 8，甲狀腺增強策略見 PDF 11。**原文 PDF 9 將 carbamazepine 的分級印成「RG C, CE 4」，與 PDF 8 和 Table I 不同；本站保留這個疑點，不自行宣布已修正。**[@M:5,8-9,11]

副作用會影響依從性與再發風險。原文比較較新藥與傳統藥的長期耐受性，同時保留性功能問題及 SSRI／骨密度、骨折疑慮；不能因此概括成新藥沒有長期風險。Quetiapine 等 SGA 需考量代謝、體重及遲發性運動障礙，而急性增強有效不代表已證實維持效果。[@M:9-10]

Carbamazepine 還涉及自體酵素誘導、CYP3A4 交互作用、低鈉、血球與肝功能變化；原文建議維持時血球／肝酵素／電解質每年 2–4 次，開始後濃度監測更密集。嚴重血液、肝臟及皮膚反應（包括 SJS）可能快速出現，患者警訊教育不能由例行抽血取代。[@M:8,10]

## 療程長度：風險持續多久？

最適停止時點尚無一致答案。原文建議再發風險仍在時持續維持；對反覆發作者，尤其前次發作在五年內、緩解不易，常考慮**三年維持**；高風險者可能五年、十年或無限期。摘要提到若兩、三次停藥嘗試後均在一年內再發，較支持很長療程。這是風險情境的建議，不是所有患者一律治療十年。[@M:2,11]

五年研究對持續足量藥物的支持，原文列 CE B／RG 3；不能據此把「五年」當作已證實普遍最佳的截止點。長期沒症狀也會使個人剩餘風險較難估計，需要和患者討論。[@M:11]

## 停藥：再發、反彈與 withdrawal

| 現象 | 本篇的區分 |
| --- | --- |
| 再發／原發作回返 | 原本的憂鬱症狀重新出現。 |
| Rebound | 原症狀以更強烈程度返回；原文特別提醒 lithium 太快停用。 |
| Withdrawal／停藥症候群 | 減藥或停藥後出現與原憂鬱發作不同的症狀組合。 |

以上區分見 PDF 11。停藥症候群可在停藥或減量數天內出現，常見暈眩、平衡／感覺異常、噁心、疲倦、頭痛、步態不穩、易怒、失眠等；原文指出短半衰期藥物如 paroxetine 較 fluoxetine 容易出現。原文對 agomelatine、vortioxetine 的當時觀察不能升格為「永遠沒有停藥反應」。[@M:11-12]

**保留兩種原文表述：**執行摘要建議長期使用後至少三個月漸減；正文對長期治療者建議 4–6 個月漸減，並加密追蹤，停藥後尤其留意接續六個月。本站沒有把它換算成每週固定減量百分比。若完整憂鬱發作回返，原文建議重新給予完整治療劑量；這和把每種不舒服都判成再發不同。[@M:3,11-12]

原文明言停藥研究有限，當時許多建議依病例／專家意見，因此時間長度與現象判讀都應保留證據侷限。[@M:11-12]

## 躁轉提示：重新檢視診斷

維持期出現躁症／輕躁症時，原文要求回頭檢視單極性診斷，並處理抗憂鬱藥及躁期治療。早發、多次早期發作、物質使用與雙極家族史等是需注意的線索；本篇轉述的轉換比例來自不同追蹤研究，不能用來預測特定患者。本站不以這個小節替代雙極性疾患的完整診療指引。[@M:3,12]

## ECT、刺激治療與心理治療

| 方式 | 維持期證據與適用情境 |
| --- | --- |
| Continuation／maintenance ECT | 本篇列 CE D／RG 5，考慮急性 ECT 完全有效、而維持藥物不適用或失敗者；不能以急性 ECT 療效直接推論維持療效。 |
| rTMS | 當時維持研究很少，CE C1／RG 4；原文指出缺少 sham-controlled 維持研究。 |
| DBS | 當時僅早期難治性憂鬱研究，尚無特定維持或長期研究可據以建立療程。 |
| VNS | 長期證據包含開放研究及不同刺激劑量試驗的事後分析，本篇列 CE C／RG 4，並指出缺乏特定維持治療 RCT。 |
| CBT／MBCT／IPT | 原文簡述預防再發的支持證據，但刻意未給 CE／RG；研究比較條件及盲性限制與藥物研究不同。 |

刺激治療見 PDF 12–13；心理治療及生活型態補述見 PDF 13–14。本篇提到的 VNS 美國核准歷史不代表各地目前核准或可近性。[@M:12-14]

CORE 試驗的延續期隨機患者為 201 人，六個月 relapse／recurrence 比例為 C-ECT 37.1%、lithium 加 nortriptyline 31.6%，兩組無統計顯著差異；**不能用「無顯著差異」直接宣布等效**。原文舉每月約一至兩次 ECT 的維持頻率，但沒有一個適合所有患者的固定排程。[@M:12]

## 特殊年齡族群

**兒童青少年：**原文討論 fluoxetine、sertraline、venlafaxine 等研究，認為延續藥物預防下一發作的證據有限。所列研究在自殺相關行為上未見顯著差異，不能等同已排除風險；成人維持證據不自動套用。[@M:14]

**高齡者：**nortriptyline 的部分研究為 CE A／RG 2，phenelzine 為 CE B／RG 3；paroxetine、escitalopram、citalopram 的特定研究支持預防再發，但 sertraline 的個別試驗未顯示顯著保護。原文引用的 Cochrane 回顧對延續 12 個月的支持受限於三項小型、異質研究；不應把它說成所有類別皆已證實等效。TCA 起始劑量與耐受性需特別考慮。[@M:14]

## 回想與自我檢查

<details class="recall-question"><summary>症狀緩解後，什麼線索支持延長維持治療？</summary><p>回想發作次數與近期性、殘餘症狀、嚴重度／自殺或精神病性特徵、停藥後復發、共病、家族史及發病年齡，再和偏好、功能與副作用一起判斷。Table II 沒有提供可直接加總的分數。[@M:2,5-6]</p></details>

<details class="recall-question"><summary>Lithium 的 0.6–0.8 mmol/L 需要附上哪兩個檢測條件？</summary><p>本篇通常建議末次服藥後 12 小時採血，且啟動或調量後不早於 5–7 天取得穩態濃度；仍需按個人反應、耐受性與臨床變化調整及監測。[@M:7,10]</p></details>

<details class="recall-question"><summary>2015 文件中的 CE A，為什麼未必都是 RG 1？</summary><p>RG 還納入風險效益。CE A 可以對應 RG 1 或 RG 2；不同指引的分級也不能直接互換。[@M:4-5]</p></details>

<details class="recall-question"><summary>停藥幾天後出現暈眩與感覺異常，能直接稱為憂鬱症再發嗎？</summary><p>要區分 withdrawal、rebound 與原症狀回返。本文列出的停藥症狀組合與時序不同於單純再發，不能把每一種不適都當作原病回返。[@M:11-12]</p></details>

<details class="recall-question"><summary>這份文件哪兩處原文問題，不能用模型記憶補正？</summary><p>Recovery 定義的「XYZ days/weeks」不能補成時間門檻；carbamazepine 的「RG C, CE 4」與另一段 CE C1／RG 4 不一致，保留兩處定位並等待確認。[@M:5,8-9]</p></details>
