# 來源紀錄

Lam RW, Kennedy SH, et al. The Canadian Journal of Psychiatry. **2024;69(9):641–687**. DOI: 10.1177/07067437241245384。

**2023 是更新版本，2024 是期刊出版年**；PDF 第 1 頁即期刊 641 頁，後續逐頁加一。不是已查核至 2026 年的最新指引。

## 範圍與方法

- 提供的 47 頁完整閱讀，含 Q1–8 正文、表格／圖、致謝、利益衝突與分章 Key References 清單。重要圖表以實際頁面檢視；橫置 Table 3.6、圖像型 Tables 3.4/3.5 與 Figure 7.1 已另放大核對。
- 更新以成人 MDD 為範圍；不把其內容視為完整的雙相、兒少、老年或周產期治療指引。文件提及這些族群或相關治療，不等於本次取得各族群完整指引。
- 搜尋期間為 2015-01-01 至 2023-05-31，優先系統性回顧與統合分析，必要時補 RCT 及其他研究。完整搜尋與證據表在未附的 OSF 補充資料，未自行下載或宣稱已讀。
- CANMAT Level 1–4、治療線別與本站 not_reviewed 狀態各自獨立；其方法雖使用 modified GRADE global ratings 評估品質／偏差，不能把表中的 CANMAT Level 或 line 直接改稱 GRADE 確定性。

## 整理時保留的重要限制

- 文件採 acute／maintenance **兩階段**，且明言 relapse、recurrence 在本指引交替使用；跨來源時不能默改成另一套分期或定義。
- Table 3.3 的劑量來自產品仿單，包含特定國家可用性註記；不是台灣即時藥品供應／核准資訊，也不是個別病人起始或調整劑量。
- Tables 3.4/3.5 分別是未校正 placebo 的仿單不良反應頻率，以及多種資料加專家共識的相對 favourability；不能當成同一組直接頭對頭比較。
- 治療線別須保留適用情境，例如 rTMS 的第一線是 **TRD 情境**；ECT 對特定嚴重情境可為第一線、對 DTD 列第二線。兩者不能只留下「第一線」標籤。
- 停藥、hyperbolic tapering、長期 adjunctive treatment、數位／AI 工具及部分神經調控療法的證據缺口照原文保留。
- 原始 PDF、擷取、頁面圖與流程原圖僅留本機，公開摘要以自己的話整理；agent 核對不等於人工醫學審閱。
