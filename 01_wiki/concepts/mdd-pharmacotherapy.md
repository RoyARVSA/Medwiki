## 藥物選擇的三個層次

1. **有療效證據，不一定等於一線。** CANMAT 的治療線別另外考量耐受性、安全、可行性；例如 TCA 與不可逆 MAOI 仍有效，卻因風險與使用負擔分列較後線。[@C:3-4,16,22,35]
2. 同屬一線不代表副作用、交互作用或個別適合程度相同。既往效果、病人重視的負擔、共病、合併藥物與偏好都需一起看。[@C:15-22]
3. **表列治療範圍不是每人的起始劑量或個別處方。** 劑量、製劑、遞增方式與監測必須放回具體情境。[@C:16,21,30]

### 二線、三線為何仍需認識？

CANMAT 將 TCA（如 amitriptyline、nortriptyline）、moclobemide、trazodone、quetiapine 等列於二線；不可逆 MAOI phenelzine、tranylcypromine 等位於三線。Dextromethorphan-bupropion 為本版加入的二線選項，保留研究量、長期安全及濫用可能等限制；不能把藥物名稱與其中單方咳嗽藥混為同一治療。[@C:16,19,35]

## 不良反應與交互作用：用問題帶出限制

| 要確認的問題 | 來源支持的重點 |
| --- | --- |
| 是否有性功能、嗜睡、失眠、腸胃或體重困擾？ | Table 3.4／3.5 分別呈現事件頻率與比較評等；兩者的意義不同，不用一個總分取代個人重視的副作用。[@C:17-18] |
| 是否合併其他 CYP 受質藥物？ | Fluoxetine、paroxetine 明顯抑制 CYP2D6；fluvoxamine 涉及 CYP1A2、2C19、3A4，需檢查整份用藥。[@C:22] |
| 是否用 NSAID 或利尿劑？ | SSRI 合併 NSAID 的腸胃出血風險、合併利尿劑的低鈉風險尤其值得注意；SNRI 也有相關風險，另留意血壓。[@C:22] |
| 是否高齡、易跌倒或已有心臟／電解質問題？ | SSRI／SNRI 的跌倒、低鈉、出血及 QTc 等風險具有年齡與情境差異；不能以「一線」免除評估。[@C:22,30] |
| 是否有肝病或代謝風險？ | 本版提到 agomelatine、bupropion、duloxetine、nefazodone 的肝臟風險；mirtazapine 的食慾、體重與長期代謝負擔。[@C:22] |
| 是否有過量服藥風險？ | TCA 過量可造成心臟毒性、癲癇及意識改變；CANMAT 提醒此情境優先考量較安全選項。[@C:22] |
| 是否涉及 MAOI？ | 與其他單胺相關藥物、St John’s wort 及高 tyramine 食物可能有嚴重交互作用。換藥 washout 另有要求，不能把一般交叉遞減直接套入。[@C:22,35] |

WFSBP 2013 舊表的 citalopram 劑量含括號中的 60 mg，但同篇另討論高劑量 QTc 風險；此為**需保留的歷史版本問題**，不將括號值轉為現在的一般建議上限。[@F:8,13]

## 啟動與停藥期間的安全追蹤

CANMAT 指出自殺相關風險與年齡、疾病狀態及治療時段均有關。抗憂鬱劑整體可減少自殺意念，但部分患者在開始治療時可能增加意念或激動；尤其需注意年輕族群。**新開抗憂鬱劑後前四週及停藥後需加強留意**，不是以「藥一定有害」或「藥一定預防自殺」概括。[@C:21]

混合特徵、活化、疑似躁／輕躁轉換須重新檢視診斷；症狀維度可以幫助討論藥物選擇，但 CANMAT 未證實某一藥對所有 anhedonia 都優於其他藥。[@C:19-21]

## 監測與額外檢查

| 情境 | CANMAT 本版的監測內容 |
| --- | --- |
| 一般抗憂鬱劑 | 無所有人一律常規抽血的要求；按臨床情境安排。 |
| 既有肝病 | 肝功能基準及每 6–12 個月追蹤。 |
| 高齡者 | Q5.d 對 ≥60 歲者提出電解質／低鈉監測的考量，依臨床情境安排；不與其他副作用段落的 >65 歲描述混成同一門檻。 |
| Lithium adjunctive treatment | Lithium 濃度、電解質、鈣、creatinine、eGFR、TSH 等基準及每 6–12 個月，或臨床狀況／劑量改變時。 |
| 與體重增加有關的藥物 | Table 5.1 列體重、葡萄糖、血脂的基準與每六個月監測；仍需個別風險評估。 |
| 長期 ketamine／esketamine | 定期尿液檢查以留意 cystitis；另有治療時血壓與解離反應等監測要求。 |

此表整理 Table 5.1／Q5.d。Lithium 藥物啟動／調整的採血時機及較密集監測需求不能被上表的長期區間取代；WFSBP 2015 在維持情境列**末次服藥後 12 小時採血，首次給藥或調量後不早於 5–7 天、達穩態後測濃度**，長期每年 1–4 次；初期、高齡或臨床變化時需更密集。版本與情境分開閱讀。[@C:28,30,37][@M:7,10]

CANMAT **不建議常規用藥物基因檢測或抗憂鬱劑血中濃度選藥**；嚴重／不尋常的低劑量副作用或足量反應差等特定情境，可另考量代謝與濃度問題。TCA 有較特定的濃度監測角色。[@C:22,35]

## 跨科連結：嚴重皮膚反應

CANMAT 將 lamotrigine 列為三線 adjunctive 選項，提醒**低劑量開始、緩慢調升及 Stevens–Johnson syndrome 風險**。精神科的用藥安全與皮膚科的病灶／黏膜辨認連到同一份 [SJS/TEN 核心頁](sjs-ten.md)，不另複製一份皮膚診斷筆記。[@C:37]
