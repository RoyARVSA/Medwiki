## 先分清介入種類與使用情境

**心理治療、運動、光照、CAM 與數位工具不是一個可互相替代的類別。** 效果取決於介入內容、執行品質、引導與支持、病情及比較對照。治療可近性與偏好很重要，但不能用方便或熱門程度代替療效與安全證據。[@C:12-15,23-28]

## 結構化心理治療

CANMAT 的建議來自受訓、受督導且具治療忠實度的研究。**不支持把不同治療各取幾個技巧，就視為具有同等實證。**[@C:14-15]

| CANMAT 本版線別 | 治療 |
| --- | --- |
| 一線 | Cognitive-behavioural therapy（CBT）、interpersonal therapy（IPT）、behavioural activation（BA） |
| 二線 | CBASP、MBCT、problem-solving therapy、short-term psychodynamic psychotherapy、跨診斷情緒疾患心理治療 |
| 三線 | Acceptance and commitment therapy、長期 psychodynamic psychotherapy、metacognitive therapy、motivational interviewing |

以上為急性 MDD 的 Table 3.2／Q3.c,f；同線別內的排序不能讀成每個人的療效排名。心理治療研究受盲性、治療者傾向、異質性等方法限制。[@C:15,19]

### 次數與頻率

CANMAT 對多數患者的一線心理治療，列 **12–16 次**為有較強證據支持的療程量；CBT／IPT 每週兩次較每週一次有較佳結果，少於每週一次的療效支持有限。這不是每個人固定第 16 次即可結案，也不是忽略治療品質、臨床需要及可近性。[@C:15]

合併藥物、或在藥物建立效果後加入心理治療，可處理殘餘症狀並預防 recurrence；嚴重且反覆發作者的序列治療，須保留持續藥物的情境。維持期 CBT、MBCT、IPT 等另見[持續與維持治療](mdd-continuation-and-maintenance.md)。[@C:14,31][@M:13-14]

## 生活型態與節律

以下依 CANMAT Table 2.4／Q2.f，線別須連同**嚴重度及單用／輔助**情境閱讀。[@C:12-13]

| 介入 | 本版的情境與細節 | 限制 |
| --- | --- | --- |
| 受督導運動 | 輕度 MDE 的一線單一介入；中度的二線輔助。低至中強度，每次 30–40 分鐘、每週 3–4 次、至少 9 週 | 研究方法與族群異質；不是對重度、高風險者的替代處理。 |
| 光照 | 冬季型季節性發作的一線單用；典型方案為每日醒後早晨 10,000 lux 白光 30 分鐘 | 非季節性輕度為二線；非季節性中度作藥物的二線輔助。保留季節性、嚴重度與單用／輔助條件。 |
| 睡眠衛生／CBT-I | 二線輔助；失眠也可能是殘餘症狀及復發風險 | 不把「改善睡眠」簡化成所有憂鬱症都由失眠造成。 |
| 健康／地中海型飲食 | 三線輔助 | 觀察關聯多於介入研究，不將關聯變成因果或單一食物療效。 |
| 睡眠剝奪／wake therapy | 三線輔助 | 效果可能短暫、研究結果不一致；易感者可能誘發輕躁。 |
| Probiotics | 證據不足以推薦治療 MDD | 「未確定」不改寫為已證實無效。 |

## CAM：天然不等於沒有風險

CANMAT 對 CAM 的單用考量限於輕度情境；中度時以標準治療的輔助為主，不能與主要心理／藥物治療的證據一概等同。St John’s wort 有產品與嚴重度相關證據，也涉及 CYP3A4 誘導及與 serotonergic 藥物合併的風險。**不能把特定萃取物的試驗，外推成所有草藥製品等效。**[@C:23-24][@M:8]

針灸研究在 sham 對照下的效果大小與臨床意義有侷限；其他補充品也各有研究品質、製劑與劑量不一致問題。詳細來源整理保留各選項，本站不從本資料包增加通用補充品處方。[@C:23-24]

## 數位介入：引導方式是重要條件

| CANMAT Table 4.3 | 情境 |
| --- | --- |
| 一線 | Guided iCBT 作輕度 MDE 的單一介入；或作輕至中度的輔助介入 |
| 二線 | 有臨床支持的 self-directed DHI 作輕至中度輔助；有臨床支持的 guided iBA 作輕至中度輔助 |
| 三線 | 無其他臨床介入可得時，輕度 MDE 才考量 self-directed DHI |
| 證據不足 | Chatbots／conversational agents 作 MDD 治療 |

Guided 並非單一標準化強度：支持者可能是治療者、教練或同儕，內容與頻率不同。不能把「有互動」或「有 AI」直接視為研究中的 guided psychotherapy。來源的例示 app 也不是 CANMAT 官方背書，更不是已確認今日仍可用或適合某個人的推薦。[@C:24-28]

### 評估數位工具的四個問題

1. **療效**：是否在相同目標族群做過試驗？功能是否符合有證據的治療內容？
2. **隱私與安全**：收集什麼、是否分享／出售、能否刪除或退出？
3. **潛在傷害**：是否延誤評估、給出錯誤資訊、缺乏危機處理或使使用者更挫折？
4. **可近性**：費用、數位識讀、語言、障礙者使用及所需時間是否合適？

以上整理自 Table 4.1；熱門、使用評價或介面美觀都不能獨立回答這些問題。[@C:25-27]
