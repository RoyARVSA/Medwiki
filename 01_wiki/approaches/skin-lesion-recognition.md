## 描述與證據



How to read a dermatology image

### 先描述，再命名

答題時先用「部位＋形態＋表面＋分布」描述照片，再接上題幹中的病程與症狀。

**01 / 形態**平的斑、隆起丘疹／斑塊、水疱、膿疱、糜爛、潰瘍，哪一種是主體？

**02 / 分布**局部或廣泛？對稱或單側？伸側、屈側、皮節、日曬區、掌蹠或黏膜？

**03 / 表面與邊界**厚銀白屑、油膩細屑、臍凹、中央開口、珠光捲邊、靶形或活動性邊緣？

**04 / 題幹證據**年齡、反覆性、用藥、接觸史、癢或痛，哪一條能改變鑑別排序？

| 描述用語 | 辨認時的意思 | 本講義常見例子 |
| --- | --- | --- |
| Macule / patch | 平坦的顏色改變；不要把所有變色區都叫丘疹。 | 白斑、汗斑、Becker 痣 |
| Papule / plaque | 隆起的實質病灶；斑塊通常較寬。 | 軟疣、乾癬、SK |
| Vesicle / bulla | 含液小水疱／較大水疱；另看疱頂緊繃或鬆弛。 | 汗皰疹、BP、PV |
| Pustule | 外觀有膿性內容物；不代表已證實細菌感染。 | GPP、AGEP |
| Scale / crust | 鱗屑為角質層片；痂為乾燥血液或滲出物。 | 乾癬 vs 糜爛後結痂 |
| Erosion / ulcer | 糜爛為表淺缺損；潰瘍侵犯更深。真正深度要檢查。 | PV 糜爛、靜脈性潰瘍 |
| Lichenification | 皮膚增厚、皮紋加深，常與反覆搔抓相關。 | 慢性 AD |
| Umbilication / punctum | 臍凹是中央凹陷；punctum 是囊腫中央開口。 | 軟疣 vs 表皮樣囊腫 |

**分清三種證據：**照片能呈現外觀與分布；癢、痛、熱度、硬度與復發病史須由題幹／檢查取得；皮膚鏡、KOH、Wood lamp、病理與 DIF 則屬另外的檢驗。本講義的「辨認特徵」包含典型臨床線索，每張圖說只描述該圖可見內容。
**使用方式：**HTML 可搜尋病名或特徵、點圖放大；PDF 可依目錄與書籤跳頁。圖片已內嵌，閱讀圖片不需連網。
